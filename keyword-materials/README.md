# Grain Rot 关键词素材进度

素材整理规则：

- 每个关键词单独保存为一个 Markdown 文件。
- 优先使用 Steam、PlayStation、Xbox、开发者页面等官方来源。

- 每条可用素材都记录来源 URL、页面标题、访问日期和信息摘要。
- 搜不到可靠信息时明确标记“未证实”，不根据关键词自行推断。
- 研究日期：2026-08-11。

## 文件内容要求

每个素材文件包含：

1. 搜索意图与建议页面定位。
2. 已核验事实。
3. Google /网页资料。
4. YouTube 资料。
5. 官网、Steam 或其他官方资料。
6. 可直接用于后续内容生成的素材摘要。
7. 冲突、缺口和禁止写成事实的内容。
