## 当前结论

官方对敌人的统一名称是 **Corrupted vessels**。发行稿将其描述为失去 Spark、或没有完全失去 Spark 的 Vessels；它们会对 **sound、movement 和彼此**作出反应，但行为难以预测。

官方没有发布正式版完整敌人名称、生命值、伤害、掉落或弱点表。2026-07-14 的官方更新只确认 1.0 相比 Demo 增加了 `New Enemies`、`Boss Encounter` 和 `Elite Encounters`，没有列名字。因此不能把 Demo 视频中的 8 个社区叫法直接包装成“正式版全部敌人”。

一份 2026-06-23 Demo 实机指南实际展示了 8 类敌人，并使用 Plague Doctor / Soul Reaper、Eye / Cyclops、Bat Guy、Stalker、Skull Head、Bomb Baby、会施加 Rot 的小孩、Crawler 等称呼。创作者在视频中多次说 `I call him...`，这些名称应标为社区描述，而非官方 Canon。

## 可直接使用的敌人页结构

1. **What are the Corrupted?**：引用官方定义和 sound / movement / each other 感知描述。
2. **Officially confirmed for 1.0**：新敌人、Boss Encounter、Elite Encounters、两个新 Biome；细节保持 TBA。
3. **Demo community bestiary**：把 8 个实机类别标为 community labels，并写明视频时间点和 Demo 版本。
4. **Universal survival**：先听声音和观察动作，避免无意义制造噪声；利用家具、陷阱、Dropkick 和队友集火；无法控制局面时撤离。
5. **Version notes**：每次正式版更新后用游戏内画面重新核对名称、生成方式、攻击模式和反制策略。

## 可用于内容生成的素材摘要

GRAIN ROT 的敌人统称 Corrupted vessels。官方解释它们是失去 Spark、或没有完全失去 Spark 的 Vessels，会对声音、动作和彼此作出难以预测的反应。正式版 1.0 在 Demo 基础上加入新敌人、Boss Encounter 和 Elite Encounters，但开发者尚未公开完整名称或数值表。

Demo 实机社区常用 Plague Doctor、Eye / Cyclops、Bat Guy、Stalker、Skull Head、Bomb Baby、Follower / Rot child 和 Crawler 等描述性称呼。它们适合做带明确 `Demo community name` 标签的观察记录，不适合直接当成官方 1.0 图鉴。正式页面应以截图中的实际 UI 名称为准，并把生命值、伤害、仇恨时间、生成池和弱点留到逐项复核后再填。

## 冲突、缺口与禁止写成事实的内容

- 不要称上述 8 个名字为官方完整名册；视频作者明确自创了部分名称。
- 不要写正式版只有 8 或 9 种敌人；官方确认 1.0 增加了新敌人，但没有发布总数。
- 不要把 Boss、Elite Encounter 和普通 Corrupted 混成同一固定生成池。
- 不要复制第三方站的生命值、伤害、弱点、掉落率、生成层数或仇恨秒数。
- 不要写所有 Corrupted 都会被手电筒吸引；官方只明确 sound、movement 和 each other，没有列光线。
- 不要把 `three-sense detection model`、pack coordination、固定 Grinder spawn trigger 或 noise budget 写成开发者机制，这些是第三方扩写。
- Demo 视频中的“击杀后从 8 个敌人池补位”“Crawler 永久锁定玩家”“Stalker 受击后永久改变状态”等观察，正式版未由官方确认。
- 官方称 Corrupted 会相互反应，不等于它们必然协同、包抄或共享完整仇恨。
