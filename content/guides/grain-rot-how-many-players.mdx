## What is the GRAIN ROT player limit?

The official GRAIN ROT player limit for ordinary crew planning is **one to four players in online co-op**. Steam also lists single-player, so a crew is optional rather than required. Four remains the group size used in the store description and release materials.

That is not the same as saying four is an absolute technical hard cap. On August 10, 2026, **Patch 1.04** added a host setting for `max player count` alongside lobby privacy controls. The patch note does not show the selectable range.

<FieldNote type="info" title="Use the two-part answer">

For ordinary purchase and crew planning, use **1–4 players**. For custom-lobby experiments, say that the host can adjust maximum player count, while the actual upper bound and performance beyond four remain unpublished.

</FieldNote>

## Solo, duo, and smaller crews

Solo is an official mode. A smaller group has fewer people to carry furniture, watch routes, or recover a displaced Spark, so the risk calculation changes even though the same extraction loop remains available.

With two or three players, avoid assigning rigid MMO-style roles that the game never defines. Instead, make sure the crew can answer three practical questions:

- Who is watching the return path?
- Who can stop scavenging to help a Spark?
- Who calls the extract when the haul is already worthwhile?

## Can more than four players join?

The current evidence supports a configurable lobby maximum, not an unlimited lobby. Community FAQ summaries describe larger groups as dependent on what the host setup can handle, but no official patch note publishes a number such as 8, 16, or 32.

Larger crews may also move outside the intended balance. More clients, voice streams, physics objects, enemies, and carried items can affect the host. Treat over-four play as a custom configuration and verify the current menu before inviting the group.

## Lobby controls added after launch

Patch 1.04 added:

- Lobby privacy.
- A configurable maximum player count.
- A **View Lobby** menu.
- Per-player microphone volume.
- Host kick and ban actions.

Patch 1.05 then fixed a problem where friends could not join when lobby privacy was set to friends. Anyone diagnosing a friends-only lobby should update first, then recreate the lobby before assuming that the privacy mode is still broken.

## What co-op is not confirmed to support

Current official listings do not confirm local split-screen, LAN, Remote Play Together, or cross-platform multiplayer. The game launched only on Windows PC through Steam, so there is no console cross-play path to document at this time.

Full controller support on the Steam PC version does **not** mean that an Xbox console version exists. Platform status is covered separately in the [Xbox guide](/platforms/xbox/) and [PS5 guide](/platforms/ps5/).
