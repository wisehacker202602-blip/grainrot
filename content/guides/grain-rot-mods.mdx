## Current mod ecosystem

Thunderstore now has a GRAIN ROT community, but the reviewed catalog is still focused on **loader infrastructure**. It contained two packages: a GRAIN ROT UE4SS compatibility overlay and its general `unreal_shimloader` dependency.

Those packages help a mod loader initialize against the game's Unreal Engine build. They are not a collection of new maps, Vessels, cosmetics, items, or gameplay systems.

## What is not available yet

No reviewed official source provides:

- A GRAIN ROT mod SDK.
- Steam Workshop integration.
- A developer mod policy.
- A verified Nexus Mods game page.
- An official statement about anti-cheat, multiplayer compatibility, or ban risk.

This is why “15 best mods” lists are premature. A trainer, loader, and content mod are different kinds of software and should not be grouped together as though they provide the same function.

<FieldNote type="warning" title="Loader does not mean safe content">

An available loader does not guarantee that every package using it is safe, compatible with the current patch, or acceptable in public multiplayer. There is no official policy to make that promise.

</FieldNote>

## Safer evaluation checklist

When actual mods appear, check all of the following before installing:

1. Package page, author, version, and update date.
2. Exact game version and loader dependency.
3. Source availability or reproducible community review.
4. Multiplayer requirements for every participant.
5. Save-file and configuration backup instructions.
6. Removal steps that do not leave injected files behind.
7. Developer policy and anti-cheat status, if published.

Do not download a random executable, DLL mirror, trainer bundle, or “all mods” installer because a search result ranks well.

## How this page will be updated

The catalog count is a dated snapshot. Once verifiable content mods exist, this guide can add a table with package name, author, function, current version, dependencies, multiplayer impact, and source link. Until then, the honest status is more useful than an invented best-mod ranking.
