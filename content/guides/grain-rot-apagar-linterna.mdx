## Tecla para apagar la linterna

La tecla predeterminada observada para la linterna es **R**:

1. Pulsa **R** una vez para apagar la linterna.
2. Pulsa **R** otra vez para encenderla.

La misma respuesta sirve para búsquedas como `apagar linterna` y `apagar luz`.

## Si la tecla R no funciona

1. Abre **Options**.
2. Entra en **Controls / Key Bindings**.
3. Busca la acción **Flashlight**.
4. Comprueba si fue reasignada o si existe un conflicto.
5. Guarda los cambios y prueba otra vez.

Una actualización anterior corrigió problemas con controles personalizados que no se guardaban. Mantén el juego actualizado antes de cambiar archivos de configuración.

## ¿La luz atrae a los enemigos?

El material oficial confirma que los Corrupted reaccionan al sonido, al movimiento y entre ellos. No publica una regla universal que diga que todos los enemigos detectan siempre la linterna. Apágala cuando necesites ver mejor la oscuridad o cuando una situación concreta lo justifique, pero no inventes una mecánica común para todos los monstruos.

La [guía inglesa para apagar la linterna](/guides/turn-off-flashlight/) contiene las fuentes y el contexto completo.
