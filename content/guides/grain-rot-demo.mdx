## Current Demo status

The standalone GRAIN ROT Demo is **not publicly available** as of August 11, 2026. The historical Demo App ID was 4731790. Its old Steam store link now returns to the storefront, the public Store API does not return active app details, and the released game's page has no Demo download control.

This proves the public listing is unavailable now. It does not prove that the developer will never reopen a Demo or limited event.

## What was in the Demo?

Videos from the Demo period show the early Deep Layer loop, room progression, perks, co-op runs, and a subset of Corrupted encounters. They are useful history and can help identify the game's basic shape.

They are not a complete version 1.0 reference. The full release added new enemies, boss and elite encounters, Spark abilities, Elevator modifiers, additional Outpost features, and new biomes. Exact Demo values and UI should be labeled by version.
