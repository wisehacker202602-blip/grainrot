## First identify the build

Before changing drivers or reinstalling runtime packages, separate the retired **Demo** from the released full game.

- Historical Demo App: **4731790** — no active public store listing during the August 11 check.
- Full game App: **4450620** — released and available on Steam.

If you are trying to download the Demo for the first time, the official public path is no longer available. An old bookmark returning to the Steam homepage is consistent with that status.

## If the Demo page will not open

There is no local fix for an inactive storefront listing. Use the [full game's official page](https://store.steampowered.com/app/4450620/GRAIN_ROT/) or follow Steam News and the official Discord for a future trial.

<FieldNote type="warning" title="Do not replace Steam with a mirror">

Avoid third-party Demo archives, cracked builds, “missing DLL” downloads, and repacked installers. The absence of an official download does not make an unofficial executable safe or authorized.

</FieldNote>

## If the Demo is already installed

An old local build can fail for many ordinary Steam reasons, but no official source identifies one universal GRAIN ROT Demo failure. Keep troubleshooting low-risk:

1. Restart Steam and the PC.
2. Open the installed game's Steam properties and verify files if Steam still exposes that action.
3. Remove custom launch options, overlays, trainers, and injected DLLs.
4. Check whether Windows Security quarantined a legitimate game file before restoring anything.
5. Do not assume an old Demo save, setting, or multiplayer environment is compatible with version 1.0.

Because the build is retired, a successful repair is not guaranteed and online services may no longer behave as old videos show.

## If the full game will not launch

Make sure you are troubleshooting App 4450620, update to the latest patch, and use Steam's normal file verification. Record the Windows version, hardware, game version, and exact error before asking for help in the official Discord or publisher support channel.

Do not attribute a launch problem to Visual C++, DirectX, a graphics driver, or antivirus without an error that supports that diagnosis.
