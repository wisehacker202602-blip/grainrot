## Xbox and Game Pass

Microsoft Store and Xbox searches did not produce a matching official release during the August 11 review. There is also no verified Game Pass announcement. See the [Xbox and Game Pass guide](/platforms/xbox/) for the evidence boundary.

## Controller support is not a console release

Steam lists full controller support for the Windows build. That means a compatible controller can be used on PC. It does not create a native PlayStation or Xbox edition, cross-play support, or a console release date.

## How to verify a future port

Treat a console version as confirmed only when at least one of these appears:

1. A developer or publisher announcement.
2. A matching PlayStation Store or Microsoft Store product page.
3. A platform and date added to the official game site or Steam news.
