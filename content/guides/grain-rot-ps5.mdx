## Current PS5 status

GRAIN ROT is **not currently listed for PlayStation 5**. The official release announcement identifies Windows PC via Steam as the launch platform, and the PlayStation Store search did not return a matching GRAIN ROT product page during the August 11 review.

IGN's current game listing also names PC without a PlayStation platform. Together, these sources support “not announced” and “not listed,” but not “cancelled” or “never coming.”

## Has a PS5 release date been announced?

No. There is no reliable PS5 date, price, performance mode, DualSense feature list, or cross-play announcement to publish. Any page providing those details without a PlayStation or developer source is speculating.

<FieldNote type="warning" title="Do not confuse demand with an announcement">

Players searching for a PS5 version show that demand exists. Search volume and fan pages do not create an official port or release date.

</FieldNote>

## How to check for a future PlayStation version

1. Search the PlayStation Store for the exact title **GRAIN ROT**.
2. Verify the developer or publisher against Beck & Branch Games and Neem Interactive.
3. Check Steam News and the official Discord for a platform announcement.
4. Ignore product pages that only reuse PC screenshots without a first-party store link.

If an official listing appears, this page will need PlayStation-specific details such as PS Plus requirements, supported player count, cross-play, save transfer, controller features, and regional pricing. None should be inferred from the Steam build.

## Can you use a PlayStation controller on PC?

Steam labels the Windows version with full controller support, but it does not publish a controller-by-controller support matrix on the store page. Controller support on PC and a native PS5 release are separate questions.
