## Verified minimum requirements

The current Steam listing identifies the following minimum Windows requirements:

| Component | Verified minimum |
| --- | --- |
| Operating system | Windows 10, 64-bit |
| Memory | 8 GB RAM |
| DirectX | Version 11 |
| Storage | 10 GB available space |
| Platform | Windows PC through Steam |

Open the live store page before purchasing to verify the current processor and graphics entries. This guide does not fill missing fields with community guesses.

## Recommended specifications

The reviewed source material does not provide a stable, separately verified recommended configuration that should be copied here as a permanent fact. Steam requirements can change after performance patches, so the live listing remains authoritative.

## macOS, Linux, and Steam Deck

The official release is listed for Windows. Full controller support is confirmed, but that does not by itself confirm native macOS, Linux, or Steam Deck support.

Avoid treating Proton community reports as an official platform guarantee. Compatibility can change with the game build, Proton version, graphics driver, and anti-cheat configuration.

## Performance checks before a run

1. Install the latest public game update.
2. Confirm that the game uses the intended graphics adapter.
3. Close heavy background capture or browser workloads.
4. Start with the in-game Video presets instead of editing unknown configuration files.
5. Use the [Options guide](/help/options/) for camera comfort, controls, audio, and lobby settings.
